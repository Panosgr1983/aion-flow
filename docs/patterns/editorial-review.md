# Editorial Review Process — AION Flow

## Vision

Ποιότητα περιεχομένου μέσω συστηματικής editorial review.

## Checklist

### Content
- [ ] Τίτλος υπάρχει και είναι περιγραφικός
- [ ] Περιγραφή υπάρχει και είναι κατατοπιστική
- [ ] Χωρίς placeholder text
- [ ] Χωρίς typographical errors
- [ ] Συνεπές ύφος (ίδιο πρόσωπο, ίδιος χρόνος)

### Media
- [ ] Εικόνα υπάρχει ή placeholder αιτιολογημένο
- [ ] Alt text περιγραφικό (όχι απλή επανάληψη τίτλου)
- [ ] Copyright/source συμπληρωμένο
- [ ] Διαστάσεις εικόνας σωστές
- [ ] Δεν υπάρχουν broken image URLs

### Metadata
- [ ] SEO title υπάρχει
- [ ] SEO description υπάρχει
- [ ] Status σωστό (draft/review/published)
- [ ] Verified flag σωστό
- [ ] Sort_order λογικό

### Technical
- [ ] Build περνάει
- [ ] Responsive σε 320px+
- [ ] Όχι console errors
- [ ] Όχι broken links

## Status Definitions

| Status | Meaning |
|--------|---------|
| draft | Αρχική δημιουργία, υπό επεξεργασία |
| review | Έτοιμο για editorial review |
| published | Εγκεκριμένο και δημοσιευμένο |
