# Client Approval Workflow — AION Flow

## Vision

Διαδικασία έγκρισης περιεχομένου από τον πελάτη πριν από δημοσίευση.

## Stages

1. **Draft Creation** — Content creator builds initial content
2. **Internal Review** — Editorial team reviews quality
3. **Client Preview** — Client gets preview link (no login required)
4. **Client Feedback** — Client requests changes
5. **Revision** — Content creator applies changes
6. **Approval** — Client approves
7. **Publish** — Content goes live

## Key Decisions

- Copyright clearance required for third-party images
- All metadata must be complete before approval
- Placeholder content must be flagged as such
- Client cannot publish themselves (admin-only action)
