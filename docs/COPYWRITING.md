# AION CMS — Copywriting Guide

> Κανόνες συγγραφής περιεχομένου για το AION.
>
> Αυτό το έγγραφο είναι σχεδιασμένο για:
> 1. **Developers** — ώστε να κατανοούν τη δομή που περιμένει το CMS
> 2. **AI** — ώστε να μπορεί να δημιουργεί περιεχόμενο που ακολουθεί consistent rules

---

## Voice & Tone

| Property | Rule |
|----------|------|
| **Voice** | Professional, trustworthy, helpful |
| **Tone** | Warm but formal (Greek market) |
| **Language** | Greek (EL) primary, English (EN) secondary |
| **Audience** | Local service consumers |
| **Person** | Second person ("εσείς") |

---

## H1 Rules

### Formula

```
[Service] [Category] & [Category] με [Trust Element]
```

### Constraints

| Rule | Value |
|------|-------|
| Max words | 10–12 |
| Never start with | "Welcome to", company name |
| No generic titles | ❌ "Υπηρεσίες μας" |
| Last word | Highlight color (green accent) |

### Examples

```
Επισκευή Laptop, Desktop & Mac με Εγγύηση
Εγκατάσταση & Συντήρηση Κλιματιστικών με Εγγύηση
Security & Δορυφορικά Συστήματα με Πιστοποίηση
```

---

## Subtitle Rules

| Rule | Value |
|------|-------|
| Max words | 25 |
| Focus | Benefit-oriented |
| Structure | Problem → Solution |

---

## CTA Rules

| Type | Label | Action |
|------|-------|--------|
| **Primary** | "Καλέστε Τώρα" / "Ζητήστε Προσφορά" | `tel:` link |
| **Secondary** | "Δωρεάν Διάγνωση" / "Δωρεάν Εκτίμηση" | Scroll to contact |
| **Never use** | "Learn More", "Click Here", "Submit" | — |

---

## Trust Metrics

Always three metrics with numbers. Never generic text.

| Format | Example |
|--------|---------|
| **Big number** (bold) | **100%** |
| **Smaller label** (uppercase) | ΓΝΗΣΙΑ ΑΝΤΑΛΛΑΚΤΙΚΑ |

### Examples

- **100%** — Γνήσια Ανταλλακτικά
- **24-48h** — Χρόνος Επισκευής
- **6 Μήνες** — Εγγύηση

---

## Section Copy Rules

### Services

| Rule | Value |
|------|-------|
| Structure | Write from customer pain, not service name |
| Description | ≤25 words, benefit-focused |
| Example | "Το laptop σας δεν ανοίγει;" → "Επισκευή Laptop" |

---

### Process

| Rule | Value |
|------|-------|
| Max steps | 4 |
| Verbs | Action-oriented |
| Format | Numbered with connector line |

---

### FAQ

| Rule | Value |
|------|-------|
| Min questions | 9 (for rich snippet eligibility) |
| Language | As customer would search/ask |
| Service area | One question must address location |
| Answer length | 1–3 sentences, direct, no fluff |
| Schema | Include FAQPage JSON-LD |

---

### Service Area

| Rule | Value |
|------|-------|
| Format | Natural copy (no keyword stuffing) |
| Areas | 5–8 surrounding areas |
| Also in | Footer + FAQ |

---

## Forbidden Patterns

| Pattern | Reason |
|---------|--------|
| "Καλωσήρθατε στο…" | Generic, no value |
| "Είμαστε η καλύτερη εταιρεία…" | Unsubstantiated |
| "Πατήστε εδώ" | Bad UX for CTA |
| Keyword stuffing | Hurts SEO |
| Fabricated case studies | Credibility is fragile |
