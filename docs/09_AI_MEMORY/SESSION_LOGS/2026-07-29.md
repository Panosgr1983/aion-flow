## Key Decisions

1. **`announcement_show_dates` default = false (opt-in).** No DB entry = false. Pattern: `=== "true"`. Kolokotronis seeded to `false`. Other tenants enable via CMS toggle.

2. **Canonical category model.** `normalizeBlogCategory()` maps individual names (ΟΜΙΛΙΕΣ, ΣΕΜΙΝΑΡΙΑ) to combined canonical (ΟΜΙΛΙΕΣ ΣΕΜΙΝΑΡΙΑ). UI shows canonical-only filter buttons. DB stores canonical combined values.

3. **`renderTipContent()` hardened with full node-type coverage.** Handlers for: doc, paragraph, heading, bulletList, orderedList, listItem, image, horizontalRule, hardBreak, codeBlock, blockquote, text (with marks: bold, italic, strike, underline, link, code). All text + attrs pass through `escapeHtml()`. Prose CSS in `styles.css`.

4. **Rich-text storage remains TipTap JSON.** No format change. All fixes in renderer and editor. Backward-compatible with all existing content.

5. **Multi-project deploy order: CMS first → verify → public site second.** Never public site before CMS verified.

6. **Root cause analysis over "fixed".** All changes document why original behavior was wrong, not just what changed.

7. **2026-07-29 = Process Baseline (not Performance Baseline).** Timing metrics not recorded from first command. Performance measurement begins next release.
