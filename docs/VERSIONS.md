# AION CMS — Version History & Conventions

## Version Convention

```
v<major>.<minor>.<patch>

major: Breaking changes (απαιτεί migration, rollback plan)
minor: Νέες λειτουργίες (backward compatible)
patch: Bug fixes (no schema changes, no new features)
```
