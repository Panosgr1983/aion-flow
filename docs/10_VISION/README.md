# 10_VISION — Future State Documents

**Domain:** Strategic Vision
**Rule:** Vision ≠ Implementation

## Purpose

This directory contains **strategic vision documents** — what we envision for the future of AION. These are NOT implementation plans. They do NOT affect the current roadmap, current development, or current AKES documentation.

## Critical Rule

Documents in `01_` through `09_` represent **current state** — what exists today, what is implemented, what is proven.

Documents in `10_VISION` represent **future state** — what we envision but has NOT been approved for implementation.

**Developers and AI assistants must NEVER confuse vision with implementation.**

## Vision Documents

| Document | Status | Description |
|----------|--------|-------------|
| `AION_ECOSYSTEM.md` | Vision | The three-product vision: FLOW + AKES + NEXUS |
| `NEXUS_VISION.md` | Vision | Production AI Orchestrator — grounded, evidence-first |
| `PULSE_VISION.md` | Vision | Future telemetry and event pipeline |

## When a Vision Becomes Implementation

A vision document transitions to implementation only when:
1. Explicitly approved by the project owner
2. A concrete implementation plan exists
3. Resources are allocated
4. The current AKES state supports it

Until then, it remains in `10_VISION` as a reference, not a directive.
